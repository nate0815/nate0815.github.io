# NA23.Chiao

**Chiao(NA23)的個人網站:遊戲開發心得、讀書筆記與作品集。** 線上網址:https://nate0815.github.io/

Hexo 8 + Fluid 主題,推上 `main` 由 GitHub Actions 自動部署到 GitHub Pages。

---

## 怎麼跑起來

```bash
npm ci
npx hexo server
```

瀏覽器打開 http://localhost:4000 ,看到首頁的字元招牌與精選作品就是跑起來了。

前置需求:Node.js 22。
